GUPPI OS – Config & Secrets v1

Konfiguration wird in vier Ebenen gedacht:
Defaults -> System -> Captain -> Mission.

Höhere Ebene überschreibt niedrigere Ebene.

Secrets werden nie direkt in Projekt-YAML abgelegt.
Konfiguration enthält nur Referenzen wie:
secret://provider/key-id

Zugriff auf Credentials ist eine geschützte Guard-Aktion.
