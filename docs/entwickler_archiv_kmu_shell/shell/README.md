# Shell „KI Gateway für KMU“

**Wofür:** Das KI Gateway im Design der Präsentation „KI Gateway für KMU · B6 · SEDRA“. Die Shell hat einen Kopf mit dem Ablauf
(Aufgabe eingeben → Schutz prüfen → Entwurf erzeugen → Ergebnis prüfen → selbst entscheiden), das Werkstück in der Mitte und
das Gespräch unten, das man hochscrollen und in der Höhe ziehen kann.

**Gestaltung:** Farben, Schrift und Abstände kommen aus den Tokens `--kmu-…` in `ui/tokens.css`. Die Werkzeuge in dieser Shell
bekommen dieselben Farben über die Umlegung in `shell.css`; an ihnen ändert sich nichts.

**Grafik:** eine eigene Zeichnung (Bogen mit Licht und ein Schild), keine Bilder aus der Präsentation. Die Bilder der Folien haben
keine Urheber- und Lizenzangabe; sie kommen nur ins Repository, wenn ihre Rechte geklärt sind.

**Nachweise:** Werkzeuge mit `slot: nachweis` zeigt diese Shell nicht daneben; das Gateway hat seinen Überblick selbst.
