# GUPPI v1.20 – Self-Development Foundation

Dieses Paket setzt auf **GUPPI v1.19 PC TEST** auf und implementiert die drei vereinbarten Entwicklungsphasen als kontrolliertes Fundament.

## Produkt-DNA

- Captain First
- Local First
- Capability Before Tool
- Evidence Before Evolution
- Plan Before Code
- Candidate Before Stable
- Verify Before Accept
- Least Privilege
- Reversible Change
- Learn From Results

## Modellstrategie

- Primäre lokale Modellfamilie: **Qwen3.5**
- Lokale Decision-/Verification-Schicht: **Kev**
- Externe Modelle: nur optionale, explizite Eskalation

## Neu in v1.20

- Capability Admission Gate
- Development Contract
- Context Manifest + Context Budget Manager
- Development Evidence Chain
- Candidate-/Verification-Contracts
- persistenter Self-Development Job Store
- E1/E2/E3 Evolution Policy
- E3 Core Protection (`may_activate=false` unveränderlich)
- Baseline-vs-Candidate Comparator
- unabhängige Verifier-Bindung
- Kev Loopback Provider Adapter
- Qwen3.5 + Kev Hardware-Pair-Presets
- Hardware-Model-Pass Pair-Fit und Execution Modes
- Capability Learning Store mit Captain-Promotion zu `KNOWN_GOOD`
- Self-Development ViewModel/API

## Wichtige Grenze

v1.20 ist **kein vollautonomer Selbstumbau**. Die Architektur kann Capability Gaps kontrolliert in Entwicklungsjobs, Contracts, Kandidaten, Tests und Verifikation überführen. Reale automatische Modell-Coding-Loops, echte Kev-Gewichte/Server und die vollständige Windows-PC-Abnahme sind weiterhin separat zu qualifizieren.
