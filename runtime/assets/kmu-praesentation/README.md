# Assets: Präsentation „KI Gateway für KMU · B6 · SEDRA“

**Quelle:** `KI-Gateway-fur-KMU-B6-SEDRA-2.pdf` (neuere Fassung, 11 Folien). Die Fassung ohne „-2“ hat den gleichen Text und
unterscheidet sich nur in den Bildern der Folien 2, 4 und 9; diese Assets stammen aus der neueren Fassung.
**Lizenz:** laut Klaus geklärt (19.10.2026). Die Bilder sind gerenderte Glas-3D-Motive ohne eingebettete Urheberangabe.

## Inhalt
- `folie-NN-bild-1.png`: die eingebetteten Bilder je Folie, unverändert (Folien 1, 2, 4, 9, 11).
- `kopf-ausschnitt-1x.png`, `kopf-ausschnitt-2x.png`: Ausschnitt aus Folie 1 (Schild mit Datenstrom), gerendert in zwei Größen.
- `design-ableitungen.json`: die gemessenen Farben und Typografie-Werte (gleiche Werte wie die `--kmu-…`-Tokens in `ui/tokens.css`).

## Eingebunden
Nur der Kopf der Shell `gateway-kmu` nutzt den Ausschnitt; dafür liegt eine Kopie als `uix/shells/gateway-kmu/kmu-grafik.png`
(der Server liefert nur Dateien direkt im Shell-Ordner aus). Die übrigen Bilder sind noch nicht eingebunden.
