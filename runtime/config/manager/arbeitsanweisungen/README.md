# Arbeitsanweisungen (dritte Ebene)

Rangfolge: Verfassung vor Gesetze vor Arbeitsanweisung. Bei Widerspruch gilt die höhere Ebene.
Eine Arbeitsanweisung darf nur einschränken oder konkretisieren, nie erweitern (Werkzeuge ⊆ Gesetze, `cloud` nur für Aufgaben aus `cloud_aufgaben`).
Eine Datei je Aufgabentyp: `<typ>.md` mit YAML-Kopf (`typ`, `werkzeuge`, `cloud`) und Text.
Änderungen nur per Antrag mit Freigabe des Captains. Geprüft wird in `verfassung.py` (`lade_arbeitsanweisung`).
