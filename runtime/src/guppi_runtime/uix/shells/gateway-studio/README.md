# KI GateWay Studio (Shell aus Vorgabe)

Die Shell für das KI GateWay (Captain 15.10., 10:13): das Werkstück füllt den Bildschirm, der Nachweis „Schutz“ steht daneben,
das Gespräch unten. Die **Orte** liegen verborgen am linken Rand und fahren heraus, wenn der Zeiger den Rand anfährt (oder per
Tastatur hineinkommt); die **Instrumente** ebenso am oberen Rand. Strg+K öffnet die Palette. Kein Shell-Code: `ui/frame.js`
baut sie aus `shell.vorgabe.yaml` (`einblenden: rand` ist seit Build 19 eine Eigenschaft des Rahmens).
