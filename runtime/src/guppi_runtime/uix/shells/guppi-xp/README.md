# GUPPI XP – der alte Desktop als Shell

`uix/retro_desktop.html` (Build 6) bleibt unverändert im Archiv unter `/retro`. Diese Shell macht ihn im Einstieg wählbar: wer sie
nimmt, landet auf der alten Seite; die Werkzeuge des Vertrags (Gespräch, Werkbank, Entscheidungen …) gibt es dort nicht.

Zurück in eine neue Oberfläche: `START_SEDRA` (Übersicht) oder `START_SEDRA cockpit`. Die Abnahme (`uix_check --shell guppi-xp`)
prüft nur, dass die alte Seite mit Desktop lädt – alles andere „nicht geprüft“, denn es gibt dort keine Vertragsmarken.
