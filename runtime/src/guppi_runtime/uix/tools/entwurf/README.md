# Werkzeug `entwurf` – Entwurf: Gespräch und Vorschau

Links das Gespräch mit einem Cloud-Modell (Wahl wie im Gespräch), rechts die Vorschau des Entwurfs. Hat das Modell eine
HTML-Seite geschrieben (Codeblock ```html), übernimmst du sie mit „In Vorschau zeigen“. Sie wird im Entwurfsordner gespeichert
und in einem isolierten Rahmen gezeigt.

Persönliche Angaben gehen wie im Gespräch nur nach den Regeln des Captains (Modus, siehe KI Labor).
