# Figur: der blaue Seedrache

Hintergrundfigur für SEDRA, gebaut mit Three.js (Version 0.160.0, von jsdelivr geladen, nur bei Bedarf).

**Verwendung:** `sedraDrache.mount(container)` in ein Element mit fester Höhe. Die Figur ist transparent und füllt den Container.
`stop()` auf das Ergebnis beendet Animation und Speicher.

**Bewegung:** Der Körper schlängelt sich, die Flossen schlagen, die Kamera fährt langsam. Bei `prefers-reduced-motion`
steht die Figur still.

**Dateien:** `drache.js` (Figur), `README.md` (diese Datei), `vorschau.html` (Testseite, im Ordner `docs/` abgelegt).
