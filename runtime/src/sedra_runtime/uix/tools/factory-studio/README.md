# Factory Studio (App)

App „Factory Studio“ (F3-01, SPEC_F3_01_FACTORY_STUDIO_APP): Project Browser und Status Dashboard (lesend) in einem App-Reiter der Harness-Shell.

- **One Sedra (`harness`):** die Shell zeichnet die App selbst, `shells/harness/factory_studio.js`: Project Browser (lesen) und Status Dashboard (lesen). Das Platzhalter-Werkzeug bleibt leer.
- **Andere Shells:** Hinweis auf die App.
- **Erste Stufe nur:** keine Schreibaktionen, kein Gate Panel, kein Start eines Builds. Eigene Texte einsprachig deutsch.
- Keine Route, kein Speicher. Nicht gebaut: Gate Panel, Execution View, Build-Start.
