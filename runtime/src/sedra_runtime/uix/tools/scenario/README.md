# Szenario Studio 0.2.0

Eigenständige SEDRA-App: Modulkatalog, runde Module/Router, Formular für Feldzuordnung,
Routen und Bündelübersicht des tatsächlichen Laufergebnisses. An Make angelehnt;
kein Make-Dienst, kein eingebettetes Make und keine Make-Blueprint-Kompatibilität.
Eigene Oberfläche und Bedienung, gemeinsame Prozessdaten, Versionen und Sicherheit
mit n8n Workflows. Keine Querimporte zwischen Apps; Basis in uix/ui/workflow-*.js.
Objekttyp scenario verhindert doppelte Editoren beim Öffnen eines Workflows.
