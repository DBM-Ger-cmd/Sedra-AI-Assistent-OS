# Team (App)

Platzhalter für den Objekttyp `team` (A3, `docs/SPEC_APP_TEAM_v1.md`).

- **One Sedra (`harness`):** die Shell zeichnet die App selbst, `shells/harness/team.js`: sechs Modus-Reiter, im Überblick Posteingang, Issues, Organigramm und Kosten zugleich. Die Werkzeuge `decisions`, `board`, `intent`, `org`, `routines`, `meter` bleiben unverändert.
- **Andere Shells:** Knöpfe, die die Werkzeuge einzeln öffnen.
- Keine Route, kein Speicher. Die alte Shell `paperclip` bleibt bis zur Abnahme des Gleichstands unverändert.
- Nicht gebaut: Agentenfenster-Stapel am Rand, Hinweise auf `agent.changed` / `budget.warning`.
