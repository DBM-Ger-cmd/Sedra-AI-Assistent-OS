# Translator (App)

Platzhalter für den Objekttyp `translator` (A3, `docs/SPEC_APP_TRANSLATOR_v1.md`).

- **One Sedra (`harness`):** die Shell zeichnet die App selbst, `shells/harness/translator.js`: Wolke, vier Modus-Reiter, Zustand je Modus, Übergaben (Transkript → Übersetzer, Rekorder → Transkript). Die vier Werkzeuge `uebersetzer`, `nachrichten`, `rekorder`, `transkript` bleiben unverändert.
- **Andere Shells:** vier Knöpfe, die die Werkzeuge einzeln öffnen.
- Keine Route, kein Speicher. Die alte Shell `fisch` bleibt bis zur Abnahme des Gleichstands (TR-50, TR-51) unverändert.
