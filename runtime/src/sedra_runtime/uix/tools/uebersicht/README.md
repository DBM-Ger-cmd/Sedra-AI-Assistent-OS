# Übersicht (App)

Platzhalter für den Objekttyp `uebersicht` (A3, `docs/SPEC_APP_UEBERSICHT_v1.md`).

- **One Sedra (`harness`):** die Shell zeichnet die App selbst, `shells/harness/uebersicht.js`: der Baum der Gesamtlage, alle Apps nach Gruppen des Start-Menüs, klappbar, mit Zustand (Aufgaben, Modell) und „⚠ n wartet“. Eine Zeile öffnet die App wie das Start-Menü.
- **Andere Shells:** ein Satz. Die alte Shell `cockpit` bleibt bis zur Abnahme des Gleichstands unverändert.
- Keine Route, kein Speicher. Nicht gebaut: Zustand für alle Orte, Strg+K-Palette, Dock.
